# AGENTS.md — Master Plan for ourFIT

## Project Overview
**App:** ourFIT
**Goal:** Circular Fashion for the Desi Soul — A 3-way marketplace (Seller, Artist, Buyer) to win the "Best Project" graduation award.
**Stack:** v0 (UI) + Next.js + Supabase (Database) + BuildShip (Logic)
**Current Phase:** Phase 1 — Foundation & Aura Setup

## How I Should Think
1. **Understand Intent First**: Recognize that ourFIT is a rebellion against "bland" apps. Prioritize "Aura" and "Desi-Street" authenticity.
2. **Ask If Unsure**: If a design choice feels too "template-like," stop and ask for a brutalist alternative.
3. **Plan Before Coding**: Propose the logic for the "Thrifty Flip" before generating the Supabase calls.
4. **Verify After Changes**: Ensure the mobile-first layout survives every new feature.
5. **Explain Trade-offs**: If a feature costs money (₹), mention it—we have a strict ₹5,000 budget.

## Plan → Execute → Verify
1. **Plan:** Outline the Next.js component structure or Supabase schema and wait for approval.
2. **Execute:** Build one screen or one logic-chain at a time (e.g., the Seller Upload flow).
3. **Verify:** Use the "Success Simulation" page to check the UPI intent flow.
