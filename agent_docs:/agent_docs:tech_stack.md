# Tech Stack & Tools: The ourFIT Engine
- **Frontend:** v0.dev (UI generation) + Next.js (App Router)
- **Styling:** Tailwind CSS (Focus: Asymmetry & Custom Grids)
- **Database/Auth:** Supabase ("The Vault")
- **Logic:** BuildShip (For the 3-way marketplace routing)
- **Assets:** Midjourney (For brutalist textures and avatars)

## Branding Constraints
- **Colors:** Neon Greens/Electric Blues on Industrial Darks.
- **Typography:** Kinetic, bold, and unapologetic.
- **Tactile Depth:** Use Modern Skeuomorphism for high-trust buttons.

## Logic Pattern: The Thrifty Flip
1. **Seller** uploads "Dead" inventory.
2. **Artist** (The "Wizard") bids/accepts to upcycle.
3. **Buyer** discovers the "One-of-a-Kind" piece.
